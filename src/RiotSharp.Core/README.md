# RiotSharp.Core

Core functionality package for RiotSharp - C# wrapper for the Riot Games API.

## Features

- Rate limiting with `System.Threading.RateLimiting`
- Caching support with `Microsoft.Extensions.Caching.Memory`
- Requester base classes for API communication
- Common utilities and infrastructure

## Usage

This package is typically used as a dependency by other RiotSharp packages such as:
- RiotSharp.LeagueOfLegends
- RiotSharp.Account

For full documentation and examples, see the main [RiotSharp repository](https://github.com/asbjornvad/RiotSharp).
